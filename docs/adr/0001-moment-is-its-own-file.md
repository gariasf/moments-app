# A Moment is its own file

A Moment is saved as its own video file with the new length, not as start and end times into its Source. Sources disappear (Jellyfin's library gets cleaned up, uploads get deleted) and many can't be opened by a browser as they are (MKV, DTS audio), so a bookmark would break with its Source or need the Source rewrapped on every play. A standalone file costs disk space and a save step per Moment, and buys a Library that never depends on its Sources.
